# Movie Library

**Автор:** Байсултанов Али

## Описание

Приложение «Movie Library» — это простая программа для хранения и фильтрации информации о фильмах. Позволяет добавлять фильмы с указанием названия, жанра, года выпуска и рейтинга. Данные сохраняются в формате JSON.

## Возможности

- Добавление фильмов с проверкой корректности ввода.
- Фильтрация по жанру и году выпуска.
- Сохранение и загрузка данных из файла.
- Простой графический интерфейс на Tkinter.

## Использование

1. Запустите `main.py`.
2. Введите данные о фильме и нажмите «Добавить фильм».
3. Используйте фильтры для поиска по жанру или году.
4. Данные сохраняются автоматически.

## Примеры тестов

- Добавить фильм: «Начало», жанр: «Фантастика», год: 2010, рейтинг: 8.8.
- Фильтр по жанру: «Фантастика» — в таблице останутся только фильмы этого жанра.
- Фильтр по году: 2010 — отобразятся фильмы только за этот год.
- Ввод некорректного года (например, «две тысячи») — появится ошибка.
- Ввод рейтинга 12 — появится ошибка.
