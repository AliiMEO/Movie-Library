# Movie Library

**Автор:** [Ваше Имя Фамилия]
**Язык:** Python 3.x

## Описание
Графическое приложение для хранения личной коллекции фильмов. Позволяет добавлять фильмы с валидацией данных, фильтровать по жанру и году, а также сохранять и загружать данные в формате JSON.

## Инструкция по запуску
1. Установите Python 3.x.
2. Установите зависимости: `pip install -r requirements.txt`
3. Запустите: `python main.py`
